第一章：框架概述

1.1 Hydra框架介绍

Hydra是基于Golang实现的微服务容器框架，为开发者提供简单、统一、易扩展的服务容器解决方案。通过少量的代码集成，即可实现丰富的功能，包括集群管理、配置管理、服务注册与发现、系统监控、日志归集、链路追踪、安全访问等。

Hydra框架目前已应用于50+生产项目，经过了大量实际生产环境的验证，具有极高的稳定性和可靠性。

1.2 核心特性

1.2.1 六类服务支持

  • API服务：基于RESTful风格的API服务
  • Web服务：提供Web页面渲染能力
  • WebSocket服务：支持实时双向通信
  • RPC服务：基于gRPC的高性能远程过程调用
  • 定时任务服务：基于时间轮的定时任务调度
  • 消息消费服务：支持多种消息队列的消费

1.2.2 跨平台支持

Hydra支持Windows、Mac、Linux三大主流操作系统，可以以服务方式安装、运行、停止、卸载，满足跨平台部署需求。

1.2.3 配置管理

采用配置中心模式，中心化管理配置，本地零配置。支持以下配置源：

  • Zookeeper
  • Redis
  • 本地文件
  • 进程内配置

配置变更后自动生效，无须手动重启服务。

1.2.4 访问控制

  • 白名单、黑名单访问控制
  • Basic Auth认证
  • API KEY认证
  • JWT认证

1.4 快速开始

1.4.1 环境要求

  • Go 1.15及以上版本
  • 支持的操作系统：Windows、Mac、Linux

1.4.2 安装

go get github.com/micro-plat/hydra

1.4.3 第一个示例：构建API服务

package main

import (
    "github.com/micro-plat/hydra"
    "github.com/micro-plat/hydra/hydra/servers/http"
)

func main() {
    // 创建应用，指定平台名、系统名和服务类型
    app := hydra.NewApp(
        hydra.WithPlatName("test"),           // 平台名
        hydra.WithSystemName("apiserver"),   // 系统名
        hydra.WithServerTypes(http.API),      // 服务类型：API
    )

    // 注册服务
    app.API("/hello", func(ctx hydra.IContext) interface{} {
        return "hello world"
    })

    // 启动应用
    app.Start()
}

运行服务：

go run main.go

测试服务：

curl http://localhost:8080/hello
# 返回: hello world

1.4.4 组合服务示例

Hydra支持在同一应用中组合使用多种服务类型：

package main

import (
    "github.com/micro-plat/hydra"   
    "github.com/micro-plat/hydra/hydra/servers/http"
    "github.com/micro-plat/hydra/hydra/servers/cron"
)

func main() {
    // 创建支持API和定时任务的应用
    app := hydra.NewApp(
        hydra.WithServerTypes(http.API, cron.CRON),
    )

    // 注册API服务
    app.API("/hello", hello)
    
    // 注册定时任务
    app.CRON("/task", hello, "@every 5s") 
    
    // 启动应用
    app.Start()
}

func hello(ctx hydra.IContext) interface{} {
    return "hello world"
}

第二章：核心概念

2.1 应用模型

Hydra应用是服务的容器，每个应用可以包含多种服务类型（API、Web、RPC等）。

2.1.1 创建应用

app := hydra.NewApp(
    hydra.WithPlatName("test"),           // 平台名
    hydra.WithSystemName("apiserver"),   // 系统名
    hydra.WithClusterName("prod"),        // 集群名
    hydra.WithServerTypes(http.API),      // 服务类型
)

2.2 服务类型详解

2.2.1 API服务

提供RESTful风格的HTTP API接口，是最常用的服务类型。

app := hydra.NewApp(
    hydra.WithServerTypes(http.API),
)
app.API("/users", usersHandler)
app.Start()

2.2.2 Web服务

提供Web页面渲染和静态文件服务。

app := hydra.NewApp(
    hydra.WithServerTypes(http.WEB),
)
app.Web("/", indexHandler)
app.Start()

2.2.3 WebSocket服务

支持实时双向通信。

app := hydra.NewApp(
    hydra.WithServerTypes(http.WS),
)
app.WS("/chat", chatHandler)
app.Start()

2.2.4 RPC服务

基于gRPC的高性能远程过程调用。

app := hydra.NewApp(
    hydra.WithServerTypes(rpc.RPC),
)
app.RPC("/user", userService)
app.Start()

2.2.5 定时任务服务

基于时间轮的定时任务调度。

app := hydra.NewApp(
    hydra.WithServerTypes(cron.CRON),
)
app.CRON("/sync", syncHandler, "@every 5s")
app.Start()

2.2.6 消息消费服务

支持Kafka、Redis、MQTT等消息队列消费。

app := hydra.NewApp(
    hydra.WithServerTypes(mqc.MQC),
)
app.MQC("/queue", handler, "queue-name")
app.Start()

2.3 生命周期钩子

2.3.1 服务级别钩子

// 服务启动前
services.Def.OnSetup(func(conf app.IAPPConf) error {
    return nil

// 服务启动后

    return nil
}, http.API)

// 服务关闭前

// 请求处理后
services.Def.OnHandleExecuted(func(ctx hydra.IContext) interface{} {
    ctx.Log().Info("请求结束")
    return nil
})

第三章：HTTP服务开发

3.1 API服务基础

3.1.1 创建API服务

package main

import (
    "github.com/micro-plat/hydra"
    "github.com/micro-plat/hydra/hydra/servers/http"
)

func main() {
    app := hydra.NewApp(
        hydra.WithPlatName("test"),
        hydra.WithSystemName("apiserver"),
        hydra.WithClusterName("prod"),
        hydra.WithServerTypes(http.API),
    )

    // 注册路由
    app.API("/hello", helloHandler)
    app.API("/users", usersHandler)
    app.API("/users/:id", userHandler)

    app.Start()
}

func helloHandler(ctx hydra.IContext) interface{} {
    return "hello world"
}

func usersHandler(ctx hydra.IContext) interface{} {
    return []map[string]interface{}{
        {"id": 1, "name": "张三"},
        {"id": 2, "name": "李四"},
    }
}

func userHandler(ctx hydra.IContext) interface{} {
    id := ctx.Request().GetMap()["id"]
    return map[string]interface{}{
        "id":   id,
        "name": "用户" + id,
    }
}

3.1.2 配置API服务

// 配置API服务监听端口8090
hydra.Conf.API("8090")

// 配置带超时和请求头读取超时
hydra.Conf.API("8090", api.WithHeaderReadTimeout(30), api.WithTimeout(30, 30))

3.2 请求参数处理

3.2.1 获取请求参数

func handler(ctx hydra.IContext) interface{} {
    // 获取所有参数（Query + Body + Path）
    params := ctx.Request().GetMap()
    
    // 获取特定参数
    name := ctx.Request().GetMap().GetString("name")
    age := ctx.Request().GetMap().GetInt("age", 0)
    
    // 获取Body
    body, _ := ctx.Request().GetBody()
    
    return map[string]interface{}{
        "params": params,
        "name":   name,
        "age":    age,
    }
}

3.2.2 参数绑定到结构体

type UserRequest struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
    ID   string `path:"id"`  // 路径参数
}

func handler(ctx hydra.IContext) interface{} {
    user := &UserRequest{}
    if err := ctx.Request().Bind(user); err != nil {
        return fmt.Errorf("参数绑定失败: %v", err)
    }
    return user
}

3.3 响应处理

3.3.1 基本响应

func handler(ctx hydra.IContext) interface{} {
    // 普通字符串 - text/plain
    return "success"
    
    // Map/Struct - application/json
    return map[string]interface{}{"name": "colin"}
    
    // XML字符串 - application/xml
    return `colin`
}

3.3.2 使用Response对象

func handler(ctx hydra.IContext) interface{} {
    resp := ctx.Response()
    
    // JSON响应
    resp.JSON(200, map[string]interface{}{"code": 0, "msg": "success"})
    
    // 文件下载
    resp.File("/path/to/file.zip", nil)
    
    // 重定向
    resp.Redirect(302, "/newlocation")
    
    // 停止执行
    resp.Abort(401, "unauthorized")
    
    return nil
}

3.4 访问控制

3.4.1 白名单

    WhiteList(whitelist.NewIPList("/**", whitelist.WithIP("192.168.4.121")))

3.4.2 黑名单

3.5 认证

3.5.1 JWT认证

// 配置JWT，排除登录接口
hydra.Conf.API("8080").
    Jwt(jwt.WithExcludes("/member/**"), jwt.WithHeader())

// 登录时设置JWT信息
func login(ctx hydra.IContext) interface{} {
    userInfo := &UserInfo{UID: "209867923", Name: "colin"}
    ctx.User().Auth().Response(userInfo)
    return "success"
}

// 获取JWT中的用户信息
func getUserInfo(ctx hydra.IContext) interface{} {
    userInfo := &UserInfo{}
    ctx.User().Auth().Bind(userInfo)

3.5.2 Basic认证

hydra.Conf.API("8080").
    Basic(basic.WithUser("admin"), basic.WithPassword("123456"))

3.6 限流

    Limit(limiter.WithRate(100), limiter.WithBurst(50))

  • WithBurst(50): 允许50个突发请求

第四章：RPC服务开发

4.1 RPC服务概述

RPC（Remote Procedure Call）服务基于gRPC协议，提供高性能的远程过程调用。Hydra框架内置gRPC支持，可以方便地创建RPC服务。

4.1.1 创建RPC服务

package main

import (
    "github.com/micro-plat/hydra"
    "github.com/micro-plat/hydra/hydra/servers/rpc"
)

func main() {
    app := hydra.NewApp(
        hydra.WithPlatName("test"),
        hydra.WithSystemName("rpcserver"),
        hydra.WithClusterName("prod"),
        hydra.WithServerTypes(rpc.RPC),
    )

    // 注册RPC服务
    app.RPC("/user", userService)

    app.Start()
}

var userService = &UserService{}

type UserService struct{}

func (s *UserService) Handle(ctx hydra.IContext) interface{} {
    return map[string]interface{}{
        "id":   1,
        "name": "张三",
    }
}

4.2 配置RPC服务

4.2.1 基本配置

// 配置RPC服务监听地址
hydra.Conf.RPC(":8090")

4.2.2 消息大小配置

hydra.Conf.RPC(":8090",
    rpc.WithMaxRecvMsgSize(10*1024*1024),  // 最大接收消息大小：10MB
    rpc.WithMaxSendMsgSize(10*1024*1024),  // 最大发送消息大小：10MB
)

4.3 gRPC基础

4.3.1 定义Proto文件

syntax = "proto3";

package user;

option go_package = "userpb";

service UserService {
    rpc GetUser (GetUserRequest) returns (User);
    rpc CreateUser (CreateUserRequest) returns (User);
    rpc ListUsers (ListUsersRequest) returns (ListUsersResponse);
}

message GetUserRequest {
    string id = 1;
}

message CreateUserRequest {
    string name = 1;
    int32 age = 2;
}

message User {
    string id = 1;
    string name = 2;
    int32 age = 3;
}

4.3.2 生成Go代码

protoc --go_out=. --go_opt=paths=source_relative \
    --go-grpc_out=. --go-grpc_opt=paths=source_relative \
    user.proto

4.4 RPC客户端

// 获取RPC客户端
client := hydra.C.RPC().GetRPC("test/rpcserver/rpc/prod")

// 调用RPC服务
func callRPCService(ctx hydra.IContext) interface{} {
    resp := hydra.C.RPC().Invoke("test/rpcserver/rpc/prod", "/user", map[string]interface{}{
        "id": "1",
    })
    return resp
}

Hydra框架的定时任务服务基于时间轮（Time Wheel）算法实现，具有高性能、低资源消耗的特点。

)

func main() {
    app := hydra.NewApp(
        hydra.WithServerTypes(cron.CRON),
    )

    // 注册定时任务
    // 参数：路由路径、处理器函数、CRON表达式
    app.CRON("/sync", syncDataHandler, "@every 5s")

    app.Start()
}

func syncDataHandler(ctx hydra.IContext) interface{} {
    // 定时执行的业务逻辑
    return "sync success"
}

5.2 CRON表达式

5.2.1 常用表达式

表达式 说明 示例

@every 5m 每5分钟执行一次 @every 5m
@every 1h 每小时执行一次 @every 1h

8.3 缓存组件

8.3.1 配置Redis缓存

// 使用Redis缓存

8.3.2 使用缓存

func getUserFromCache(id int64) (string, error) {
    cache := hydra.C.GetCache()
    key := fmt.Sprintf("user:info:%d", id)
    
    // 尝试从缓存获取
    value, err := cache.Get(key)
    if err == nil {
        return value, nil
    }
    
    // 缓存不存在，从数据库获取
    user, err := queryUser(id)
    if err != nil {
        return "", err
    }
    
    // 存入缓存
    data, _ := json.Marshal(user)
    cache.Set(key, string(data), 3600)  // 缓存1小时
    
    return string(data), nil
}

8.4 分布式锁

func processWithLock(lockName string, fn func() error) error {
    lock, err := hydra.C.DLock(lockName)
    if err != nil {
        return err
    }

    ok, err := lock.TryLock(10) // 10秒超时
    if !ok {
        return fmt.Errorf("获取锁失败")
    }
    
    err = fn()
    lock.Unlock()
    
    return err
}

第九章：上下文与请求处理

9.1 IContext核心接口

IContext是Hydra框架的核心接口，封装了请求的所有信息。

9.1.1 获取请求参数

func handler(ctx hydra.IContext) interface{} {
    // 获取所有参数
    params := ctx.Request().GetMap()
    
    // 获取特定参数
    name := ctx.Request().GetMap().GetString("name")
    age := ctx.Request().GetMap().GetInt("age", 0)
    
    // 获取请求头
    headers := ctx.Request().Headers()
    token := headers.GetString("Authorization")
    
    // 获取Cookie
    cookies := ctx.Request().Cookies()
    sessionID := cookies.GetString("session_id")
    
    return params
}

9.2 响应处理

13.2 服务降级

服务降级是在系统压力过大或服务不可用时，通过返回备用响应来保证系统整体可用性的机制。

13.2.1 降级配置

// 配置API服务，启用限流和降级
hydra.Conf.API("8080").Limit(
    limiter.NewRuleList(
        limiter.NewRule("/api/order",
            10, // 每秒允许10个请求
            limiter.WithMaxWait(5),       // 最多等待5秒
            limiter.WithFallback(),       // 启用降级
            limiter.WithResp(429, `{"code":-1,"msg":"服务繁忙，请稍后重试"}`),
        ),
    ),
)

13.3 熔断

熔断机制是在服务持续出现错误时，暂时切断对该服务的调用，避免级联故障。

13.3.1 熔断配置

// 配置限流/熔断规则
hydra.Conf.API("8080").Limit(
    limiter.NewRuleList(
        limiter.NewRule("/api/external",
            50,  // 每秒允许50个请求
            limiter.WithMaxWait(1),  // 最多等待1秒
            limiter.WithResp(503, `{"code":-1,"msg":"服务暂不可用"}`),
        ),
    ),
)

package main

import (
    "github.com/micro-plat/hydra"
    "github.com/micro-plat/hydra/hydra/servers/http"
)

func main() {
    app := hydra.NewApp(
        hydra.WithPlatName("ecommerce"),
        hydra.WithSystemName("api"),
        hydra.WithClusterName("prod"),
        hydra.WithServerTypes(http.API),
    )

    // 商品接口
    app.API("/products", productList)
    app.API("/products/:id", productDetail)
    
    // 订单接口
    app.API("/orders", createOrder)
    app.API("/orders/:id", getOrder)
    
    app.Start()
}

func productList(ctx hydra.IContext) interface{} {
    return []map[string]interface{}{
        {"id": 1, "name": "商品A", "price": 100},
        {"id": 2, "name": "商品B", "price": 200},
    }
}

func productDetail(ctx hydra.IContext) interface{} {
    id := ctx.Request().GetMap()["id"]
    return map[string]interface{}{
        "id":    id,
        "name":  "商品A",
        "price": 100,
    }
}

func createOrder(ctx hydra.IContext) interface{} {
    params := ctx.Request().GetMap()
    return map[string]interface{}{
        "order_id": "ORDER123",
        "status":   "created",
    }
}

func getOrder(ctx hydra.IContext) interface{} {
    id := ctx.Request().GetMap()["id"]
    return map[string]interface{}{
        "order_id": id,
        "status":   "paid",
    }
}
